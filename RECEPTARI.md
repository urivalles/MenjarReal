# Inventari de receptes de MenjarReal

El catàleg incorporat conté **96 fitxes**. N’hi ha 31 a «Les meves», 55 a «Descobrir» i 10 a «Exemples anteriors». L’inventari recull la base compartida de l’app. Les adopcions i les receptes personals de cada navegador poden fer variar aquests totals.

De MyRealFood hi ha **29 fitxes amb foto**. En 22 es veuen la preparació i la llista d’ingredients. La pasta amb pesto té la quantitat de pasta pendent. Set fitxes tenen dades parcials, entre les quals hi ha dues fotos de «Capritxos/snacks» amb el títol tallat. La captura general mostra també les carpetes «Mis favoritas» i «Sopars». La tria de receptes d’aquestes dues carpetes queda per confirmar.

## Cobertura del receptari

| Tipus | Fitxes per cuinar a «Les meves» i «Descobrir» |
| --- | ---: |
| Dinar o sopar | 61 |
| Guarnició o entrant | 14 |
| Esmorzar | 2 |
| Berenar o snack | 9 |
| Postres | 3 |
| Base o component | 1 |

Una recepta pot aparèixer en més d’un tipus. Dels 61 dinars o sopars, 44 indiquen 30 minuts o menys. En 45 destaquen la verdura, una font de proteïna i una font d’hidrats segons els ingredients principals.

## Peix i guarnicions

Hi ha 14 fitxes de peix i 3 de marisc o cefalòpodes. Les vuit receptes de peix noves són a «Les meves» i indiquen entre 8 i 20 minuts. Set inclouen verdura i una base d’hidrats. L’orada amb moniato està pensada per a quan ja tens una guarnició feta.

Les guarnicions ara inclouen vuit preparacions noves de 8 a 12 minuts. N’hi ha al microones, com l’albergínia amb llimona i comí, i també de paella o sense cocció. El buit més clar del receptari són els esmorzars, amb dues fitxes amb informació suficient per preparar-los a les col·leccions principals.
